Глобальная конфигурация {% if global_config %} Версия: {{ global_config.version }} {% endif %}
Как это работает: При изменении глобальной конфигурации, все агенты получат новую версию при следующей отправке метрик.
Персональные конфигурации агентов
Внимание: Эта конфигурация переопределяет глобальные настройки только для выбранного агента.
Примеры конфигураций
Важно: Конфигурация применяется к агенту полностью. Агент заменяет свой текущий конфиг полученным от мастера. При изменении версии глобального конфига, агенты автоматически получат обновление при следующей отправке метрик.
Минимальная конфигурация
{
  "metrics": {
    "cpu": true,
    "ram": true
  },
  "agent_runtime": {
    "interval_seconds": 10
  }
}
Только CPU и RAM, интервал 10 секунд
Полная конфигурация
{
  "metrics": {
    "cpu": true,
    "ram": true,
    "disk": true,
    "network": true,
    "system": true,
    "load_avg": true
  },
  "agent_runtime": {
    "interval_seconds": 10,
    "retry_attempts": 3,
    "retry_delay": 2
  }
}
Все метрики включены, стандартные настройки сети
Частый опрос (нагрузка)
{
  "metrics": {
    "cpu": true,
    "ram": true,
    "network": true,
    "disk": false,
    "system": false,
    "load_avg": false
  },
  "agent_runtime": {
    "interval_seconds": 5,
    "retry_attempts": 5,
    "retry_delay": 1
  }
}
Быстрый опрос важных метрик каждые 5 секунд
Структура конфигурации агента:
Секция Параметр Тип Описание
metrics cpu boolean Сбор CPU (cpu_percent)
ram boolean Сбор RAM (ram_percent, ram_used, ram_total)
disk boolean Сбор диска (disk_percent, disk_used, disk_total)
network boolean Сбор сети (net_bytes_sent, net_bytes_recv)
system boolean Сбор системы (uptime_seconds)
load_avg boolean Сбор Load Average (load_1min, load_5min, load_15min)
agent_runtime interval_seconds number Интервал отправки метрик (секунды)
retry_attempts number Количество попыток при ошибке
retry_delay number Задержка между попытками (секунды)
